# O que é o safepdf?

É uma forma mais segura para abrir arquivos pdfs de fontes não confiáveis.

## Instalação dos requerimentos

Os pacotes e bibliotecas necessárias estão nos arquivos "package_requiriments.txt" e "requiriments.txt".

## Como usar

Abra o pdf suspeito em uma VM, então execute o programa e digite o número total de páginas do pdf, logo após execute o programa, tem 10 segundos (configuravel no arquivo main) para abrir a VM e focar na janela.

## Recomendações

- Executar o pdf não confiável em uma VM com rede isolada ou sem acesso a internet.
- Utilizar VM em tela cheia.
